# Portfolio — Durgesh Khushlani

Personal portfolio for Durgesh Khushlani, AI Engineer & Backend Engineer. Built with Next.js (static export), Tailwind CSS, and the Doto + Geist Mono font pairing.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

Outputs a static export to `out/` (`output: "export"` in `next.config.ts`).
